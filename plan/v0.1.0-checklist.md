# Release v0.1.0 - MVP Implementation Checklist

This is a detailed implementation checklist for the Foundation/MVP release.

## Backend Tasks

### User Profile System
```
Priority: HIGH
Estimated: 2-3 days
```

- [ ] **Database Schema**
  - [ ] Add avatar_url column to users table (if not exists)
  - [ ] Create follow_relationships table
    ```sql
    CREATE TABLE follow_relationships (
        id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
        follower_id UUID REFERENCES users(id) ON DELETE CASCADE,
        following_id UUID REFERENCES users(id) ON DELETE CASCADE,
        created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
        UNIQUE(follower_id, following_id)
    );
    ```
  - [ ] Add indexes for fast lookup

- [ ] **API Endpoints**
  - [ ] GET /api/v1/users/:id - Get user profile
  - [ ] PUT /api/v1/users/me - Update own profile
  - [ ] POST /api/v1/users/:id/follow - Follow user
  - [ ] DELETE /api/v1/users/:id/follow - Unfollow user
  - [ ] GET /api/v1/users/:id/followers - List followers
  - [ ] GET /api/v1/users/:id/following - List following

- [ ] **Handlers & Services**
  - [ ] UserService with follow logic
  - [ ] Input validation (bio max length, display name rules)
  - [ ] Prevent self-following
  - [ ] Follow counts caching

## Blockers/Risks

- **Risk:** Image processing could be slow
  - **Mitigation:** Use async processing queue (v0.2)
  
- **Risk:** Storage costs for images
  - **Mitigation:** Compression, size limits, cleanup job

- **Risk:** Privacy concerns with public profiles
  - **Mitigation:** Add privacy settings (v0.2)
