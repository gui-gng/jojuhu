# v0.4.0 Frontend Implementation Plan

## Current Status

## Backend Features Ready for Frontend

### 1. Privacy & GDPR (7 endpoints)
- `GET /api/v1/privacy/settings` - Get privacy settings
- `PUT /api/v1/privacy/settings` - Update privacy settings
- `POST /api/v1/privacy/data-export` - Request data export
- `GET /api/v1/privacy/data-export` - Check export status
- `POST /api/v1/privacy/account-deletion` - Request account deletion
- `GET /api/v1/privacy/account-deletion` - Check deletion status
- `POST /api/v1/privacy/account-deletion/cancel` - Cancel deletion

### 2. Scheduled Posts (5 endpoints)
- `POST /api/v1/scheduled-posts` - Create scheduled post
- `GET /api/v1/scheduled-posts` - List scheduled posts
- `GET /api/v1/scheduled-posts/{id}` - Get scheduled post
- `PUT /api/v1/scheduled-posts/{id}` - Update scheduled post
- `POST /api/v1/scheduled-posts/{id}/cancel` - Cancel scheduled post

### 3. Post Drafts (3 endpoints)
- `POST /api/v1/drafts` - Save/update draft
- `GET /api/v1/drafts` - Get current draft
- `DELETE /api/v1/drafts` - Delete draft

### 4. Push Notification Tokens (2 endpoints)
- `POST /api/v1/push-tokens` - Register device token
- `POST /api/v1/push-tokens/deactivate` - Deactivate token

### 5. Groups & Moderation (~25 endpoints)
**Groups:**
- Create, join, leave groups
- Group invitations
- Join requests
- Role management

**Moderation:**
- Report content
- Moderation dashboard
- User suspensions

### 6. Link Preview (1 endpoint)
- `POST /api/v1/link-preview` - Get URL metadata
