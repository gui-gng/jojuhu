### API Endpoints

#### Groups
```
POST   /api/v1/groups
GET    /api/v1/groups
POST   /api/v1/groups/:id/join
POST   /api/v1/groups/:id/leave
GET    /api/v1/groups/:id/members
PUT    /api/v1/groups/:id/members/:user_id/role
POST   /api/v1/groups/:id/invite
POST   /api/v1/groups/:id/join-requests
GET    /api/v1/groups/:id/join-requests
GET    /api/v1/groups/invitations
POST   /api/v1/groups/invitations/:id/accept
POST   /api/v1/groups/invitations/:id/reject
POST   /api/v1/groups/join-requests/:id/approve
POST   /api/v1/groups/join-requests/:id/reject
```

#### Moderation
```
POST   /api/v1/reports
GET    /api/v1/admin/reports
PUT    /api/v1/admin/reports/:id
```

#### Analytics
```
GET    /api/v1/users/me/analytics
GET    /api/v1/forums/:id/analytics
```
