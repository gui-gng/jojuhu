### API Endpoints

#### Groups
```
POST   /api/v1/groups
GET    /api/v1/groups
```

```
POST   /api/v1/reports

PUT    /api/v1/admin/reports/:id
```

#### Analytics
```
GET    /api/v1/users/me/analytics
GET    /api/v1/forums/:id/analytics
```
