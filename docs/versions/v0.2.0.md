## Technical Implementation

### WebSocket Architecture
```
Client ←→ Nginx ←→ Actix-web WebSocket
                ↓
           PostgreSQL (messages)
                ↓
           Redis Pub/Sub
```

### Notification Flow
1. Action triggers notification (like, comment, etc.)
2. Notification saved to database
3. Published to Redis channel
4. WebSocket server broadcasts to recipient
5. Client receives real-time notification
